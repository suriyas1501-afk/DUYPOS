# ระบบขายหน้าร้าน (POS)

ระบบ POS ภาษาไทยแบบ **offline-first** — ข้อมูลทั้งหมดเก็บในเครื่อง (IndexedDB) ขายต่อได้แม้อินเทอร์เน็ตหลุด ติดตั้งเป็นแอปได้ (PWA)

## ฟีเจอร์ (เฟสแรก — MVP สาขาเดียว)

- 🛒 **หน้าขาย** — ยิงบาร์โค้ด (รวมบาร์โค้ดแพ็ค/ลัง) / เลือกจากกริดสินค้า, ตัวเลือกสินค้า (หวานน้อย, เพิ่มช็อต ฯลฯ), ขายชั่งน้ำหนัก (0.5 กก.), ราคาขายส่งอัตโนมัติ, พักบิล/เรียกบิล, ส่วนลดรายการ/ท้ายบิล, **จ่ายผสมหลายช่องทางในบิลเดียว**, **QR พร้อมเพย์ฝังยอด**, เลขคิว + สลิปครัว, พิมพ์ใบเสร็จ 58/80 มม.
- 🏷️ **โปรโมชัน** — ลด %, ลดเงิน, ซื้อ X แถม Y (เลือกใช้อัตโนมัติ)
- 🎟️ **คูปอง (e-Coupon)** — โค้ดส่วนลด จำกัดจำนวนครั้ง/ยอดขั้นต่ำ/เพดานส่วนลด/ช่วงเวลา
- 👥 **สมาชิก** — สะสมแต้ม แลกแต้มเป็นส่วนลด
- 📦 **สินค้า & สต็อก** — หมวดหมู่, บาร์โค้ด, หลายหน่วยขาย (ชิ้น/แพ็ค/ลัง), ราคาส่ง, รูปสินค้า, นำเข้าสินค้าจาก CSV, แจ้งเตือนใกล้หมด
- 🚚 **รับของเข้า** — รับทีเดียวหลายรายการ อัปเดตต้นทุน ผูกซัพพลายเออร์ และลงบัญชีรายจ่ายให้อัตโนมัติ
- 📋 **นับสต็อก** — นับของจริงเทียบระบบ สรุปมูลค่าของขาด/เกิน แล้วปรับยอดทีเดียว
- 🧾 **ประวัติการขาย** — ดูบิลย้อนหลัง, พิมพ์ซ้ำ, **คืนสินค้าบางรายการ** (คืนสต็อก/แต้มตามสัดส่วน), ยกเลิกบิล, **ออกใบกำกับภาษีเต็มรูป**
- 🧮 **ใบกำกับภาษีเต็มรูป / ใบลดหนี้** — ครบองค์ประกอบตามมาตรา 86/4 (ข้อมูลผู้ขาย-ผู้ซื้อ, แยก VAT, จำนวนเงินเป็นตัวอักษร), พิมพ์ A4 ต้นฉบับ+สำเนา, ยกเลิกใบพร้อมเหตุผล, ทะเบียนใบทั้งหมด + ส่งออก CSV
- 👤 **พนักงาน & สิทธิ์** — เข้าใช้งานด้วย PIN, บทบาทเจ้าของร้าน/ผู้จัดการ/พนักงานขาย, เปิด-ปิดสิทธิ์รายคน, ล็อกหน้าจออัตโนมัติ, **ให้ผู้จัดการใส่ PIN อนุมัติ** เมื่อพนักงานจะให้ส่วนลด/ยกเลิกบิล/คืนสินค้า, ทุกเอกสารบันทึกชื่อผู้ทำรายการ
- 🕐 **กะ & ลิ้นชักเงินสด** — เปิด/ปิดกะ, เงินทอนตั้งต้น, นำเงินเข้า-ออกลิ้นชัก, **ใบนับเงินแยกธนบัตร/เหรียญ** เทียบกับยอดที่ควรมี (เกิน/ขาด), พิมพ์รายงานปิดกะ
- 📊 **รายงาน** — ยอดขายรายวัน, สินค้าขายดี, กำไรขั้นต้น, ช่องทางชำระ, **ยอดขายแยกตามพนักงาน**, ส่งออก CSV
- 💼 **บัญชี** — บันทึกรายจ่าย, งบกำไรขาดทุน (รายรับอัตโนมัติจากการขาย), รายงานภาษีซื้อ/ขาย (เตรียมยื่น ภ.พ.30) + กระทบยอดกับใบกำกับที่ออก, ปิดยอดรายวัน + พิมพ์สรุปลิ้นชักเงินสด
- 💾 **สำรองข้อมูล** — เลือกโฟลเดอร์ครั้งเดียว ระบบเขียนไฟล์สำรองให้เองวันละครั้ง (เก็บย้อนหลัง 14 ไฟล์) + แถบเตือนเมื่อไม่ได้สำรองนาน, กู้คืนจากไฟล์ JSON ได้ทุกเมื่อ
- ⚙️ **ตั้งค่า** — โหมดค้าปลีก ↔ คาเฟ่, VAT, อัตราแต้ม, ระบบพนักงาน/กะ/ใบกำกับภาษี, สำรอง/กู้คืนข้อมูล (JSON)

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด http://localhost:5173 — ครั้งแรกระบบจะโหลดข้อมูลตัวอย่างให้ทดลองเล่นได้ทันที (ลบได้ที่ ตั้งค่า → ข้อมูล)

ระบบพนักงาน / กะ / ใบกำกับภาษี **ปิดอยู่เป็นค่าเริ่มต้น** — เปิดได้ที่หน้า **ตั้งค่า**
เมื่อเปิดระบบพนักงาน จะมีบัญชีเริ่มต้นให้ **เจ้าของร้าน · รหัส E01 · PIN 1234** (ควรเปลี่ยน PIN ทันทีที่หน้าพนักงาน)

Build โปรดักชัน: `npm run build` แล้วนำโฟลเดอร์ `dist/` ไปวางบนเว็บเซิร์ฟเวอร์ใดก็ได้ (หรือเปิดผ่าน `npm run preview`)

## เฟสถัดไป (โร้ดแมป)

1. ห่อเป็นแอป Windows ด้วย Electron — พิมพ์ ESC/POS ตรงเครื่องพิมพ์ (ไม่มีหน้าต่างพิมพ์) + สั่งเปิดลิ้นชักเงินสด, สำรองข้อมูลอัตโนมัติลงไดรฟ์
2. เซิร์ฟเวอร์กลาง + sync หลายสาขา (Centralized POS)
3. เชื่อม ERP / โปรแกรมบัญชี

> ⚠️ ข้อมูลเก็บในเบราว์เซอร์เครื่องนั้นๆ — แนะนำกด **สำรองข้อมูล** ในหน้าตั้งค่าเป็นประจำ
