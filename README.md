# ระบบขายหน้าร้าน (POS)

ระบบ POS ภาษาไทยแบบ **offline-first** — ข้อมูลทั้งหมดเก็บในเครื่อง (IndexedDB) ขายต่อได้แม้อินเทอร์เน็ตหลุด ติดตั้งเป็นแอปได้ (PWA)

## ฟีเจอร์ (เฟสแรก — MVP สาขาเดียว)

- 🛒 **หน้าขาย** — ยิงบาร์โค้ด / เลือกจากกริดสินค้า, ตัวเลือกสินค้า (หวานน้อย, เพิ่มช็อต ฯลฯ), พักบิล/เรียกบิล, ส่วนลดรายการ/ท้ายบิล, จ่ายเงินสด·โอน·บัตร, พิมพ์ใบเสร็จ 58/80 มม.
- 🏷️ **โปรโมชัน** — ลด %, ลดเงิน, ซื้อ X แถม Y (เลือกใช้อัตโนมัติ)
- 👥 **สมาชิก** — สะสมแต้ม แลกแต้มเป็นส่วนลด
- 📦 **สินค้า & สต็อก** — หมวดหมู่, บาร์โค้ด, รูปสินค้า, รับเข้า/ปรับปรุงสต็อก, แจ้งเตือนใกล้หมด
- 🧾 **ประวัติการขาย** — ดูบิลย้อนหลัง, พิมพ์ซ้ำ, ยกเลิกบิล (คืนสต็อก/แต้มอัตโนมัติ)
- 📊 **รายงาน** — ยอดขายรายวัน, สินค้าขายดี, กำไรขั้นต้น, ช่องทางชำระ, ส่งออก CSV
- 💼 **บัญชี** — บันทึกรายจ่าย, งบกำไรขาดทุน (รายรับอัตโนมัติจากการขาย), รายงานภาษีซื้อ/ขาย (เตรียมยื่น ภ.พ.30), ปิดยอดรายวัน + พิมพ์สรุปลิ้นชักเงินสด
- ⚙️ **ตั้งค่า** — โหมดค้าปลีก ↔ คาเฟ่, VAT, อัตราแต้ม, สำรอง/กู้คืนข้อมูล (JSON)

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด http://localhost:5173 — ครั้งแรกระบบจะโหลดข้อมูลตัวอย่างให้ทดลองเล่นได้ทันที (ลบได้ที่ ตั้งค่า → ข้อมูล)

Build โปรดักชัน: `npm run build` แล้วนำโฟลเดอร์ `dist/` ไปวางบนเว็บเซิร์ฟเวอร์ใดก็ได้ (หรือเปิดผ่าน `npm run preview`)

## เฟสถัดไป (โร้ดแมป)

1. ห่อเป็นแอป Windows ด้วย Electron (โค้ดชุดเดียวกัน)
2. เซิร์ฟเวอร์กลาง + sync หลายสาขา (Centralized POS)
3. กะพนักงาน / สิทธิ์ผู้ใช้, เชื่อม ERP/บัญชี

> ⚠️ ข้อมูลเก็บในเบราว์เซอร์เครื่องนั้นๆ — แนะนำกด **สำรองข้อมูล** ในหน้าตั้งค่าเป็นประจำ
